## 1. 从纯白棚拍改成生活场景：换了什么、丢了什么

|       | v1 纯白棚拍版（留档）           | **v2 生活化场景版（本版）**                               |
| ----- | ---------------------- | ----------------------------------------------- |
| 背景    | 无缝纯白影棚，柔和均匀布光          | 真实使用场景：小院 / 大草坪 / 修边 / 木料区 / 车库工作台，自然日光         |
| 动态来源  | 只有高光在机壳上流动，画面偏「会动的静物图」 | **环境本身会动**：草叶被微风轻拂、树影光斑缓慢移动、远处树叶轻晃。机器仍静止，但画面活得多 |
| 首帧    | 直接用已验收的白底主图，零新增素材      | **必须先出 32 张「场景定稿图」**&#x4F5C;首帧（§4），多一轮 32 次生成   |
| 型号一致性 | 一级锁定（主图 → 视频）          | 两级锁定（主图 → 场景定稿图 → 视频），多一道静态验收关卡                 |
| 视觉语言  | 与产品图完全一致               | 与 §3 已验收 hero / 用例场景图同一语汇，演示店整体更连贯              |

**换来的**：生活感、环境微动、与已验收场景图的视觉连贯性。  
**丢掉的 / 多付的**：① 32 张新增 AI 图，生成次数从 32 次变 **64 次**，且这 32 张要按 §9.3 补登记；② 场景定稿图必须 **1:1**，已验收的 8 张 hero 图是 16:9 / 3:4，**只能当视觉参考，不能拿来当首帧**；③ 自然日光下机器配色有漂移风险（绿变黄、灰黑泛蓝），需逐张验；④ 场景里最容易冒出**门牌号、信箱字样、工具标签、包装文字、车牌**，反向词与自查项都变长；⑤ 两级锁定多一道人工验收。

### 1.1 为什么不能只把提示词里的「纯白影棚」换成「小院草坪」

首帧是白底棚拍主图，提示词却要求户外场景 → 模型从第 1 帧起就要把纯白背景重绘成庭院，**机器会被连带重画一遍**。§4 用翻车换来的那些一致性问题会整套回来：电池款长排气管、42Z 长方向盘、配件表面冒假刻字，而且动态画面没法逐帧查。

正确做法是两级锁定，和 `asset-provenance.md` §4 的「两步出图工作流」同一套逻辑：

```
已验收主图（白底/透明底，形态权威）
      │  ① 以主图为即梦参考图，出一张「该机器在生活场景中」的 1:1 定稿图
      ▼
场景定稿图（静态，可逐张验收：形态对不对、有没有冒字、光照有没有把颜色带偏）
      │  ② 以这张场景图为视频首帧，提示词只描述「怎么动」
      ▼
视频（首帧已在场景里，不存在场景切换，机器不需要被重绘）
```

这也正是上一版 §1 预留的升级路径：「先出一张该机器在场景中的定稿图，再以它为首帧做图生视频」。

### 1.2 场景里可以有「使用过的痕迹」，不能有「正在作业」

- ✅ 允许：刚割过的草痕与割草条纹、集草袋里装着草屑、木段端面与地面碎木屑、石板缝边待修的杂草、工作台上的扳手。这些都是**静态证据**，不牵动机器形态。
- ❌ 禁止：机器自行前进、刀盘切草、草屑飞溅、锯链切入木段、有人在推机器。这些都会让模型重绘整机（§7 B 档列了风险分级，默认不开）。
- 「实际使用场景」不等于「必须有人」：SDD §9.3 要求避免可识别的真实人物，本版 32 条一律**无人物、无手、无脸、无宠物**。已验收 hero 场景图同样是无人场景。

### 2.2 由主题实现推导出的约束（别踩）

1. **视频不能排在媒体第一位。** `main-product.liquid` 的 `--gallery-ratio` 取 `product.media.first.preview_image.aspect_ratio`，而视频的 `preview_image` 是 Shopify 自动截的封面帧。首位放视频 → 整个画廊框比例由视频封面帧决定，后面所有 2048×2048 方图被 `object-fit: contain` 塞进去，出现大片留白。**挂媒体时排在两张产品图之后。**
2. **比例必须 1:1。** 同上：非 1:1 视频即使不排首位，切到该张时也会在方框里上下留黑边。**这一条同时约束场景定稿图**——32 张新图一律 1:1，不能沿用 hero 的 16:9 / 3:4。
3. **不带音轨。** 主题是用户点开才 `play()`，带声会被策略拒绝 → 触发静音重试，观感是「卡一下」。静音源最稳。
4. **alt 必填。** 主题把 `media.alt` 直接用在封面图的 `alt` 上（SDD §8.2 无障碍）。规则：沿用该款主图 alt，前缀 `Video: `，描述机器与画面实质（场景版还要点出场景），不写「产品视频」这种空壳。
5. **封面帧天然一致**：Shopify 自动截首帧做 `preview_image`，而我们的首帧就是场景定稿图 → 封面即场景全景，不需要另做封面图。
6. **⚠️ 强制项 15 的三场景缺口（与素材无关，是主题侧）**：SDD §7.1 第 15 条要求视频在 `product` / `featured product` / `quick view` 三类场景都能播放。2026-11-06 全仓核实（`sections/` 32 个 liquid + `snippets/` + `assets/` + `templates/`）：
   - `product` → `sections/main-product.liquid` 四类媒体齐全 ✅
   - `featured product` → 只有 `sections/featured-collection.liquid`（集合型，走 `snippets/product-card.liquid`，该 snippet 只渲染 `product.featured_image` 一张静态图）；**没有单品 featured-product section**
   - `quick view` → 全仓无商品快速查看弹窗组件。⚠️ 注意 `sections/product-highlights.liquid` 里有个名为 `spec_quickview` 的 block，**那是「决策参数卡」（5 个规格槽位），不是 quick view**，别被同名误导
   也就是说这 32 条视频挂上去后，只会在产品页画廊出现；卡片与 quick view 仍是静态图。素材到位不等于该条验收到位，需单独确认口径（见 §9）。

### 2.3 待实测 / 待核验（写在这里，不许当成已定参数）

- **即梦（Seedance）当前界面的时长档位、比例档位、分辨率档位、运镜幅度档位**：第三方教程口径互相矛盾（时长有 3/6/9/12s、4/6/8s、4–15s 三套说法），**以实际界面为准，首次出片后回填校正**。§3 里的数字是**建议值，不是平台限制，也不是工具硬指标**。
- **视频生成的商用许可与水印策略**：`asset-provenance.md` §2 里图片工具的商用许可仍是「⚠️ 待核验并登记」状态。视频生成可能走不同套餐条款、不同水印规则，**必须单独核验并登记**（条款链接/截图存档路径、核验人/日期均待填）。第一批「豆包AI生成」水印的教训对视频同样成立，且视频水印会在帧内抖动、更难发现。
- **场景定稿图的商用许可**：与产品图同工具同套餐的话沿用同一份核验；若换模型/换入口，须单独登记。
- **视频/3D 能否作为变体媒体**：第三方引官方 add-media 页称「不能」，未逐字复核；演示店 32 款全为单变体，此限制不触发，暂不影响出片。

## 4. 场景定稿图准备（两级锁定的第一级，32 张）

### 4.1 出图工作流（沿用 `asset-provenance.md` §4 的参考图模式）

1. 上传该款**已验收主图**作即梦参考图（透明底 `_rmbg` 或白底合成版均可，形态权威是它）。
2. 复制 §4.2 模板，把 `<场景>` 换成 §4.4 矩阵里该行的场景词，出 1:1 方图。
3. 按 §4.3 自查；不过就重出，**别把有问题的图拿去当视频首帧**——第一帧错了，整条视频都白做。
4. 定稿图上传 Shopify Files，按 §4.5 登记到 `asset-provenance.md`。
5. 该图即 §6 对应条目的首帧。

### 4.2 场景定稿图提示词模板（即梦·直接复制）

```
参考图中的机器保持原样，不要变更产品任何特征、颜色、比例与部件：把这台机器自然放进<场景>，
机器与地面有真实接触阴影，光线与环境一致，写实生活化场景摄影，照片级真实感，1比1方图。
无任何文字、无标志、无型号标、无门牌号、无信箱字样、无包装标签、无工具刻字、无车牌、
无水印、无人物、无手、无脸、无宠物、无第二台机器、无假刻字、无多余部件。
```

> `<场景>` 逐款取 §4.4 矩阵第 4 列。模板与 `asset-provenance.md` §5 的「细节图（参考图模式）」同构：  
> 先声明「不要变更产品任何特征」，再描述新增内容（那里是细节，这里是环境）。

### 4.3 场景定稿图自查（静态图，逐张过）

① 机器形态与参考主图一致（电池款无排气管 / 42Z 无方向盘 / 42TH 遮阳篷在 / 21PH 大后轮没缩水）；  
② 场景里**没有任何文字**：门牌号、信箱、栅栏挂牌、工具包装、机油瓶标签、车牌、花盆印刷字；  
③ 自然日光**没有把配色带偏**（绿仍是绿、灰黑仍是灰黑、红黑仍是红黑）；  
④ 地面接触关系成立（不是浮在草上）、投影方向与环境光一致；  
⑤ **1:1 方图**，不是 16:9 / 3:4；⑥ 无人物、无手、无宠物、无第二台机器。

## 7. 可选「微动增强句」（B 档，非默认）

§6 的 32 条全部是**机器静止、环境微动 + 镜头运动**的保守档。场景版已经比棚拍版活（草叶、树影、光斑都在动），默认够用。若还想要「正在作业」的感觉，可按下表替换，替换后**必须逐帧复核**——模型在让机器或部件动起来时最容易顺手重绘整机，这是场景版最贵的一块风险。

| 品类 | 可替换句 | 风险 |
| ---- | -------- | ---- |
| 小院 / 大草坪割草机 11 款 | 机器保持静止，仅排草口附近有少量草屑被气流轻扬、草叶随之倒伏 | 中；草屑容易牵动刀盘与整机形态 |
| 修边场景（打草机 5 款） | 机器保持静止，仅打草头前方几根杂草被气流压弯 | 中；易牵动整个切割头旋转 |
| 木料场景（链锯 5 款） | 机器保持静止，仅原木端面有极少量细木屑浮尘在逆光里飘 | 低；**导板与锯链绝不转动** |
| 工作台场景（配件 11 款） | 保持静物，仅窗外树影光斑在台面移动幅度略增 | 低；但不得让工具或配件自行移动 |
| 屏幕/指示灯类（电池 B40） | **不建议替换** | 高；指示灯处最容易被吐出数字/文字 |
| 锯链 / 导板配件 | **禁止替换** | 锯链一转，链齿数量与导板长度几乎必崩，§4b 已把「锯链转动」列为禁区 |

> 一句话判据：**让环境动，别让机器动**。机器一动，§1.1 的两级锁定就白做了。

### 8.1 出片后的落地流程（顺序不能反）

1. §4 备齐 32 张场景定稿图（按 §4.3 逐张验收 + §4.5 登记）→ 2. 按 §3 参数 + §6 提示词出片 → 3. 按 §5「六件事」自查，不过就重出 → 4. 导出 `video-*-1-scene.mp4`（1:1 / 1080P / 无音轨 / H.264）→ 5. **Shopify 后台逐个商品**「媒体 → 上传视频」，**排在两张产品图之后**（§2.2 第 1 条）→ 6. 填 `alt`（沿用主图 alt + `Video: ` 前缀）→ 7. 回填本表日期 / 挂载 / alt / 状态 → 8. 在产品页真机点开播一次，确认 `<template>` 延迟实例化、播放按钮、静音降级链路都正常。

> 没有「回填 CSV / IMAGES 字典」这一步。SDD §5.9：3D 与视频不支持 CSV。

### 8.2 建议的分批顺序（按演示价值，不按编号）

`asset-provenance.md` §4c 已说过配件「本身就是细节，再出细节图边际价值低」——视频同理，且配件 11 款的场景只是工作台静物。建议：

- **P0（建议先做 4–6 条）**：V-01 小院走步汽油、V-05 小院走步电池、V-08 大草坪驾乘、V-11 大草坪 zero-turn、V-17 木料区链锯、V-12 修边打草机 —— 覆盖动力源、机型与三类新增场景语汇，足够把强制项 15 的播放链路跑通，也顺便验证场景定稿图工作流。
- **P1**：其余主机 15 款。
- **P2**：配件 11 款。若时间紧，可考虑合成 1 条配件总览视频挂到某个主机上，但那样就不是「每款一条」了，需刘工拍板。

**总成本（不藏）**：32 张场景定稿图 + 32 条视频 = **64 次生成**，加 32 次后台手动上传 + 32 次逐帧自查 + 32 张图的 §9.3 登记。比 v1 棚拍版整整多一轮出图。按单人作战排期，建议先跑 P0 的 6 张场景图验证工作流，再决定要不要全量铺开。
