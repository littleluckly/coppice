**第 2 件：把删掉的三段用注释加回来**（供逐段放开）

- 用的是 **HTML 注释 `<!-- -->`**，不是 `{%- comment -%}`。原因：Liquid 注释块遇到内层
  `{%- endcomment -%}` 会**提前闭合**，后面的大段标记会漏出来变成生效代码；`theme check`
  当时仍报 0 error（H 变体踩过）。而 A/B/C 三段内部各自带大量 `{%- comment -%}`，所以只能走 HTML 注释。
- 代价（已告知刘工，非白拿）：HTML 注释里的 Liquid **仍会被服务端执行、内容仍会传输**，
  只是不渲染。所以注释回收站不是零成本，调试结束后应当删除，而不是长期留着。
- 三段之间留了 `{%- comment -%} 【A】… {%- endcomment -%}` 这样的**分节标签**，方便逐段定位与放开。
