## T-1.7 第九轮：BUG-034 + popular 产品阵列 + View all（同日）

- **BUG-034**：hover 移入 mega 面板途中自动收起。根因——第六轮的行 padding 加在 inner 上，li 只包住 44px trigger，trigger 与面板之间 16px"死亡区"不在 hover 链上。修复：padding 移到 `.main-nav__item` 自身（li 覆盖整行）。
- **教训**：hover 链组件加 padding 前画命中区链路图——**padding 加在目标自身（或其祖先链上的元素）才保持链路连续；加在"包含目标的旁支容器"上会制造盲区**。

- **View all products**：左列底部链接 `routes.all_products_collection_url`。扫盲结论已答刘工：/collections/all 是官方内置路由，天然存在无需建集合；demo 里的 "All Speakers (11)" 是商家自建分类集合（非 /collections/all），模式 = 集合链接 + all_products_count 徽标——本主题组头 "All Mowers (n) →" 即此模式。

## T-1.7 第十一轮：换行/图标/LCP 答疑/淡入（同日）

- 卡内文字溢出根因：`.main-nav__inner` 的 `white-space: nowrap`（导航行约定）继承进面板——**行级排版约定放在容器上会沿 DOM 渗透到所有后代**，面板类容器要显式重置。inner 恢复 normal，左列分类名单独 nowrap。
- LCP 答疑结论（已答刘工，不用 template）：display:none 面板不参与渲染不进 LCP 候选；面板图全 lazy，无盒子即无 viewport 相交 = 首屏零请求；template 省几 KB HTML 但杀掉无 JS 可用性（T-1.3 红线）。**"display:none + lazy" 是隐藏面板的标准答案，template 只用于"JS 专属"内容**。
- 切换淡入只做单侧（新组 @starting-style opacity 0→1）：两组同在文档流，双向过渡（allow-discrete 延迟摘除）会布局跳动。
- reduced-motion 补 `.main-nav__mega-card-img`（hover 缩放此前遗漏）。
- 人日：第十一轮 0.25，总额 11.75，剩余 1.5。第十三轮（卡内呼吸感）并入；第十四轮（呼吸感二档：容器级间距 + 等高卡）并入不另计。
- 等高卡套路：grid li 默认 stretch 但**卡链接自身会缩回内容高**——link 也要 flex column + width:100%，末行信息（价格/计数）margin-top auto 沉底。**"stretch 只管 grid item，不管 item 的子元素"**。
- 呼吸感调优次序：先卡内 → 再卡间 → 最后容器 padding/组间；压抑感多是容器级问题，别只盯卡内。
- 顶部对齐：多区块首行对齐要管两层——**盒顶（flex-start 自动）+ cap 顶（小字行盒顶留白比大字小，需微沉补偿）**；图卡顶对齐的是行盒不是 cap，微差可接受。补偿公式：字号差 × (body行高−0.7)/2；一轮 0.125rem 不够（行高实测大于估算），二轮 0.375rem——**这类 1-2px 字面齐平不要两轮猜，首轮就该把公式和 devtools 锚点写进注释**。
