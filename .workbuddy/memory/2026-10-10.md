### 关键架构决策：为什么拆成 snippet + section 两个文件
**section 不能被 render 到其他文件**（Shopify 限制），但 O-4 要求 Shopify 必须能按 `section_id` 单独重渲染**结果块**并返回 HTML 片段。两个需求冲突，解法：
- **结果块 = 独立 section**（自带 stylesheet——因为响应里不含调用方，样式不共享）
- **搜索框 = snippet**，由 main-nav render 出来

### 端点（已核实官方 Predictive Search API 文档）
`/search/suggest?q=&section_id=&resources[type]=product,collection,page,article&resources[limit]=1..10&predictive_search=true`
注意是 `resources[type]` / `resources[limit]` 带方括号嵌套，不是 `type=`。

### ARIA：combobox + listbox，明确不用 dialog
DOM 焦点**始终留在 input**，方向键靠 `aria-activedescendant` 移动虚拟游标（APG 的 selection follows focus）。`<dialog>` 会吞掉按键、彻底破坏 type-ahead。
**这与汉堡抽屉的 `<dialog>` 用法不冲突**——抽屉是模态，搜索是非模态，模式不同。

### 错误分类（不是静默 catch）
422 参数非法 / 417 买家 locale 不支持 / 429 限流，三类分别处理，**一律不打开面板**；表单本身仍能提交到搜索结果页，搜索不至于不可用。

### 其他实现要点
- **无结果 → 整个面板保持隐藏**（官方 UX 明确不要显示空的"无结果"面板），但**始终渲染 View all 出口**，顾客不会被困住。
- **字段最小化**：只取 title / price / featured_image，**不请求 body**——官方明确多语言下 body 会混合翻译。
- 补 locale：`search.products/collections/pages/articles/instructions/view_all` + `products.product.from_price_html`（**这个键原本不存在，查出来才发现**；一度写成带 `{{ price }}` 插值但没传参，会渲染空白，改为无插值的 "From"）。
- 清除按钮用 `hidden` 属性控制显隐（不是自定义 data 属性），无输入时不出现在无障碍树。

## BUG-030 修复 + 抽屉滑入/滑出动画（刘工第二轮实测反馈）

- **close 无反应根因**：search-drawer.js 抄 nav-drawer 骨架时漏抄构造器 `bind`——`_onClose`/`_onDialogClick` 作为 listener 被调时 `this` 是 dialog/按钮本身，`this._dialog` 为 undefined，守卫短路。node --check 查不出（语法对、this 漂移）。

## BUG-031 修复：抽屉锁滚动导致页面抖动

- **根因**：critical.css 锁滚动只做 `overflow: hidden`，经典滚动条系统下滚动条退出布局 → 内容区变宽一个滚动条宽度 → 抖动。overlay 滚动条（macOS 默认）无布局宽度，无感。
- **修复**：锁滚动规则内加 `scrollbar-gutter: stable`（scoped 在 `html:has(dialog[scroll-lock][open], ...)` 内，短页面不常驻空槽）。已核实三来源：stable 在 overflow hidden 期间仍保留占位，官方推荐 modal 防跳方案。
- **教训（已记 bugs.md）**：凡隐藏滚动条的实现必须配套占位补偿——这是模态类组件标准项，进抽屉/dialog 实现检查点。
- 今日抽屉链共三连修：BUG-028（API 响应格式接线）→ 029（display:none 祖先）→ 030（漏 bind）→ 031（滚动条占位）。**浏览器实测一条链揪出四个静态检查全查不出的问题**——涉交互功能当天实测的预防条款值得长期执行。

## BUG-032 修复：sticky 不生效 + hero 通不了栏（同根）

- **sticky**：挂在 `.main-nav` 上无效——父级是 Shopify 的 `.shopify-section` 包裹 div，高度=导航行自身，sticky 无黏的空间。修法：schema 加 `"class": "main-nav-section"`，sticky 移到包裹层（body flex 子项、纵贯整页）。**Shopify 主题吸顶一律挂包裹层，不挂 section 根。**
