## T-1.7 第三轮：间距去 gap 改水平 padding（同日）

- 刘工指出：条目间 gap 是 hover 盲区，鼠标移入时药丸/深色背景异常。改为 `.main-nav__link` 自身 `padding-inline: 0.875rem`（padding 计入药丸测量范围，hover 区与药丸重合），`--main-nav-gap` 删除（仅一处引用）。

## T-1.7 第四轮：面板通栏 + 滑入滑出（同日）

- 刘工两条：①mega 面板要滑入滑出；②面板宽度占满整屏，内容区保持内容列。
- 实现：背景/投影/圆角从 inner 移到 mega 本体（通栏），inner 只管内容列对齐；滑入滑出用 `transition: display 0.22s` + 单独声明 `transition-behavior: allow-discrete`——**拆开写是关键**：合在一条 transition 声明里时，旧浏览器解析不了 allow-discrete 会把整条 transition 丢弃（连 opacity 动画一起死）；拆开则优雅降级为"开启有动画、关闭瞬时"。
- 悬停桥删除：通栏面板紧贴行底，无需桥；行与面板用 1px 细线分隔。
- 经验：**面板从悬浮卡片改通栏后，视觉属性应放在通栏元素上、内容元素只管对齐**——两层职责分开，后面再调样式不会互相牵扯。

## T-1.7 第五轮：真通栏修复 + 层下钻出（同日）

- 刘工反馈：①面板没占满屏宽；②要整个面板滑入滑出、且在导航层级之下滑入。
- 根因①：给药丸分层加的 ul/wrap `position: relative` 劫持了 mega 的包含块（面板缩到菜单宽）。删除两处定位，分层收拢到链接自身（relative+z1）；`nav-pill.js` 量测基准改 `offsetParent`（动态取包含块）。
- 方案②一版被自己推翻：行底 ::before(z2)+inner(z3)+mega(z1) 的层游戏——inner 抬 z-index 创建层叠上下文，mega 作为它的后代永远出不去。终版用 **clip-path 揭示**：隐藏态 `inset(0 0 100% 0)`（裁切边贴行底），展开 `inset(0 0 -3rem 0)` + inner `translateY(-0.75rem→0)`，视觉即"从行下抽出"，零层级依赖。阴影弃 box-shadow（被 clip 裁掉）改 `filter: drop-shadow`。
- 两条重要教训：**①绝对定位元素的包含块=最近的 positioned 祖先，给中间层加 position 会静默劫持后代面板的锚点；②"被遮住"的动画先画层叠上下文图——目标若是遮罩物的 positioned+z-index 祖先的后代，方案根本不成立，换 clip/transform 思路**。

## T-1.7 第六轮：锚点显式化 + 行 padding（同日）

- 刘工指出 offsetParent 是隐式依赖，提议用自定义属性声明定位父级。落地：desktop 加 `data-nav-pill-anchor`；JS 三态——anchor 校验通过且 =offsetParent 按约定量测 / anchor 失效回退 offsetParent / 两者不一致按**实际包含块**量测（保证视觉正确）+ console.warn（结构变化信号）。
- 刘工问"不一致时用谁"的答案：**永远按 CSS 实际包含块量测**（视觉正确优先），属性的价值是告警 + 文档化意图，不是替代包含块。
- 导航行（桌面 inner + 移动 mobile）加 `padding-block: 1rem`。
- 可复用约定：**JS 量测型组件的定位锚点一律用 data 属性显式声明 + offsetParent 交叉校验**。
