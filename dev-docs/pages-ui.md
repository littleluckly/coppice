# Coppice 页面用途与 UI 规格（开发工单）

> **性质**：开发工单——照此文档可直接实现页面结构；本文是 SDD v4.2 的**页面视角重组**，不引入新决策。
> **权威关系**：与 SDD 冲突时以 `dev-docs/sdd.md` 为准；各节标注来源章节（如 §6.2）。
> **图例**：线框为 ASCII 示意，上下顺序 = 渲染顺序；`[G]` = 来自 section group（商家可增删）；`▓` = LCP 相关。
> 整理日期：2026-09-30 ｜ 覆盖：14 个模板 ｜ 每页：桌面 + 移动双端线框

---

## 0. 全局约定（读一次，各页不重复）

**通用无障碍**（全部页面适用，详见 SDD §8.2）：每页一个 `h1`；焦点顺序 = DOM 顺序、无正 `tabindex`、禁用 `autofocus`；skip link 必备；所有 `img` 带 alt 与 width/height；动态区域（筛选计数、对比数量、加购结果、变体切换）一律 `aria-live="polite"`；抽屉/模态遵循 `role="dialog"` + 焦点锁定 + `Esc` 回焦；触摸目标 ≥ 44×44px；对比度正文 4.5:1。

**通用性能**（SDD §8.1）：所有 script `defer`/`async`；LCP 图 `fetchpriority="high"` + eager，非首屏 lazy；隐藏组件（抽屉、对比栏）**首次打开才建 DOM**；metafield 取值移到循环外。

**缺失数据通用行为**（SDD §5.4/§5.7）：参数缺值 → 该行不出现（规格表/对比表显示 `—`，**永不显示 0**）；物流 metafield 未填 → 整个物流模块不渲染；`compare_group` 为空 → 加入对比按钮 `disabled`，不兜底。

**页面主流程**（验收路径，SDD §8.3）：
`筛选(集合) → 产品页 → 加入对比 → 对比页 → 加购(主机+耗材) → 购物车 → 结账`

**metafield 定义的前置开关**（SDD §5.8，影响所有页面的数据可达性）：23 个定义全勾 Storefront 可见性 + Admin API 筛选；`battery_platform` / `area_coverage_sqft` / `power_source` 另勾"用作集合条件"。

## 1. 全局 Section Groups

### 1.1 `sections/header-group.json`（各页顶部，[G]）

**职责**：公告 + 导航 + 搜索 + 账户 + 购物车入口，商家可增删排序（SDD §4.2）。

> **实现决策（2026-10-09 拍板，与 `task-header.md` §1 一致）**：
> - **粘性**：仅 PC 端 sticky（`position: sticky` 写在 `@media (min-width: 990px)` 内），移动端随页面滚走。
> - **cart 入口**：本期只做入口 + 服务端计数 + 跳 `routes.cart_url`；**不做抽屉 / 计数联动 / 配置项**（后续单独任务清单）。
> - **搜索联想**：HTML 片段端点 `/search/suggest` + `section_id`（Section Rendering API），非 `suggest.json`；弹层为 **combobox + listbox**（非模态）。
> - **移动导航**：与桌面菜单**两套 DOM、互斥渲染**；汉堡抽屉用原生 `<dialog>` + `showModal()`（加 `scroll-lock` 属性锁背景滚动），**不手写焦点陷阱**。
> - **utility-bar**：本期启用，移动端隐藏。
> - JS 交互组件一律 **Custom Element** 封装（AGENTS.md §6）。

**菜单树规则**：

- `Shop by Platform` 与 `Support` 为独立一级入口（不嵌在 Shop 下）。
- 平台/品类集合全是**自动化集合**——商品导入并填好 metafield 后自动归入，菜单永不改链接（§4.3 底注）。
- 空集合的菜单项**暂不挂**（避免点进空页）；空集合卡片在首页/list-collections 隐藏（§2/§5 同规则）。
- Support 三项是内容入口，演示店需建 2 个 page + 1 个 blog 并填实质内容（§9.4 禁止空页）。
- 当前演示店只有割草机 → Chainsaws / Trimmers / Accessories 建集合但**暂不挂菜单**。
- **`Oils & Fuel` 机油与燃油已从主导航移除（SDD v4.3）**——不是漏写。改为两处承载：产品页耗材关联（§6.3 `acc.consumables`，本主题主转化路径）+ footer 耗材分类入口（§1.2）。理由：主导航深度已达三级上限（§7.1 #10），且机油的跨分类归属（§3.5 `Hardware > Lubricants > Oil`）使它更适合作为内容型入口。**菜单不建该节点，但集合与耗材商品照常导入**——它在产品页仍会被 `acc.consumables` 带出来。

| compare-data（§6.2.1） | `<script type="application/json" id="cmp-data">`：**只装本组白名单字段（walk/riding=11，chainsaw/trimmer=10）+ 列式编码 + ≤50 款 + 置于 DOM 末尾；只访问 metafield** | group→page 映射 | `spec.*` |
| compare-table | 服务端默认 3 款静态表（可索引、无 JS 可读）；JS 有有效选择时用**同一 snippet** 重建替换 | 默认款数 | 数据岛 + `localStorage ib:compare:v1` |
| compare-bar | 悬浮条：缩略图/移除/Compare(n)/可折叠 | — | localStorage |

**状态要点（本页最密集）**：

- 无 JS：仍见默认 3 款表与选型文案；勾选入口优雅消失（§6.2.3）。
- localStorage 为空/无效 → 不动默认表、不 `JSON.parse`（懒解析）。
- L3 渲染层校验：跨组条目剔除 + aria-live 播报；handle 不在数据岛 → 该列显式降级"不在本页数据范围"+商品链接（§6.2.6），**不静默丢列**。
- `spec_variance_note` 非空 → 该列表头提示图标 `<button aria-expanded>` + `aria-describedby`。
- 缺值 `—` 不显示 0；表格 `<caption>` + `th scope` 双向；型号列表头移动端 sticky + "下一款"键盘路径。
- 表格替换不丢焦点；载入清单 aria-live 播报且不抢焦点（§6.2.4）。
- 索引开关 `compare_page_indexing`：商家一键 noindex；canonical 恒为去参路径。
